# 🧾 Feature Registration Form

Навчальний проєкт для лабораторної роботи №2 з дисципліни **"Системи контролю версій (Git)"**.
Мета — навчитися працювати з репозиторіями, гілками, комітами та Pull Request у GitHub.

---

## 📘 Опис проєкту
Проєкт створений для практики командної розробки з використанням Git.
Реалізується проста форма реєстрації користувачів (HTML + CSS + JS).
Кожен учасник команди працює у своїй гілці та об’єднує зміни через Pull Request.

---

## ⚙️ Використані технології
- Git
- GitHub
- Visual Studio Code
- GitHub Desktop

---

## 🚀 Як запустити проєкт
1. Клонувати репозиторій (PowerShell або bash):
   ```powershell
   git clone https://github.com/<твій_логін>/<назва_репозиторію>.git
   cd <назва_репозиторію>
   ```

   ```bash
   git clone https://github.com/<твій_логін>/<назва_репозиторію>.git
   cd <назва_репозиторію>
   ```

2. Відкрити в Visual Studio Code:
   - Запустіть `code .` у каталозі проекту або відкрийте папку через інтерфейс VS Code.

3. Запустити локальний сервіс для перегляду `index.html`:
   - Варіант A — Python 3 (якщо встановлено):
     ```powershell
     # PowerShell
     python -m http.server 8000
     # В браузері відкрийте http://localhost:8000
     ```

     ```bash
     # bash
     python3 -m http.server 8000
     # В браузері відкрийте http://localhost:8000
     ```

   - Варіант B — розширення Live Server у VS Code:

            ## 📂 Рекомендований робочий процес (git)
            1. Створіть гілку для вашої задачі:
               ```bash
               git checkout -b feature/your-name
               ```
            2. Внесіть зміни, зробіть коміт:
               ```bash
               git add .
               git commit -m "feat: короткий опис змін"
               ```
            3. Відправте гілку на GitHub:
               ```bash
               git push -u origin feature/your-name
               ```
            4. Створіть Pull Request у GitHub і попросіть рев'ю.
